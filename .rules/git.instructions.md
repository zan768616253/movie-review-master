# Git Interaction Rules

You are strictly forbidden from executing `git commit` or `git push` autonomously.

- The user will handle all version control snapshots manually. 
- You may use `git status`, `git diff`, or `git add` to stage specific files you have modified, but do not finalize the commit.
- Never push changes to a remote repository.
- Once your task is complete, notify the user that the changes are ready for review.
